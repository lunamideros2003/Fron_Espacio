# AstroIA — Frontend (Vite + React)

Aplicación web del explorador inteligente del universo.

## Arranque

En una terminal, con el backend FastAPI ya corriendo en el puerto 4000:

```bash
cd Fron_Espacio
npm install
npm run dev
```

Abre http://localhost:5173

Vite reenvía `/api` hacia FastAPI (`http://localhost:4000`).
